Projects

Machine learning

Transparent conductive oxide classification

End-to-end ML pipeline classifying 5 materials (AZO, FTO, ITO, MZO, ZnO) from X-ray diffraction scans using ~359 engineered features across 6 groups. Applied physics-motivated data augmentation to grow the dataset to 640 samples, then benchmarked 15 classifiers with leakage-free repeated stratified cross-validation. Best model: LightGBM, 90.6% holdout accuracy (Cohen's κ = 0.88).

Python LightGBM XGBoost Scikit-learn
Personal project

DeltaTrain — sim racing telemetry and AI coaching

Full end-to-end telemetry system for Automobilista 2: captures live UDP telemetry (speed, RPM, throttle, brake, steering, lap position) straight from the sim, records every session to a local database with automatic lap tracking, and drives a live dashboard with real-time gauges and rolling charts. Built automatic corner detection that segments each lap and measures brake points, apex speed, and throttle application corner-by-corner, plus a "best lap possible" calculator that stitches together the fastest segment through every corner across all sessions. An AI coaching layer reads the data and reports exactly where time is being lost, and where technique is already solid. Reverse-engineered an undocumented UDP protocol and traced a subtle bug back to a 1.6-second telemetry dropout mid-lap, validating every fix against synthetic data with a known correct answer before trusting it on real laps.

Python UDP sockets SQLite WebSockets Chart.js JavaScript

MedTrack — clinic management system

Full-scale clinic management platform covering the entire patient journey from registration to pharmacy: patient registration and queueing, doctor prescription workflows, a product catalog with category filters, inventory management with stock levels and expiry alerts, panel insurance claims across 12+ providers with file uploads and status tracking, and a transaction report with receipt generation. Built with HTML, CSS, and PHP, backed by a relational database designed in phpMyAdmin to keep patient records, prescriptions, and inventory in sync across every module.

HTML CSS PHP phpMyAdmin RDBMS
Group project

F1 Smart Companion — AI race prediction app

AI-based mobile app built with a team of four for a university AI workshop, delivering race predictions, news, and driver insight in one place for F1 fans. A prediction engine trained on historical FastF1 data benchmarked XGBoost against Random Forest, a neural network, and logistic regression — XGBoost led with 95.8% average accuracy, powering a live countdown to the next Grand Prix, a projected podium, and full-grid win probabilities. Also includes "F1 Insider," an AI chatbot that summarises RSS news headlines and answers driver-specific questions, "Identify Driver AI" for photo-based driver recognition and stats lookup, and a community "Fan Pulse" driver rating system.

Python XGBoost Random Forest Pandas FastF1
